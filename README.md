# Ruby Mod (Fabric, Minecraft 26.3)

Adds a **Ruby** gem and a **Block of Ruby**.

| Recipe | Result |
|---|---|
| Amethyst Shard in the center, Redstone Dust on the 4 sides | 1 Ruby |
| 9 Rubies (3x3) | 1 Block of Ruby |
| 1 Block of Ruby | 9 Rubies |

The Block of Ruby needs an iron pickaxe or better to mine. Rubies appear in the Ingredients creative tab, and the block appears in Building Blocks.

## Build
Requires **JDK 25** (set `JAVA_HOME` to it).

    ./gradlew build          # jar lands in build/libs/rubymod-1.0.0.jar
    ./gradlew runClient      # launch a dev Minecraft with the mod

## Install
Install Fabric Loader for 26.3, then drop `rubymod-1.0.0.jar` and the matching **Fabric API** jar into `.minecraft/mods`.

## Tweaking
- Code: `src/main/java/dev/rubymod/` (`ModItems`, `ModBlocks`)
- Recipes / loot / tags: `src/main/resources/data/`
- Textures are generated by `tools/textures.py`. Edit the pixel grids there, then run
  `python tools/textures.py src/main/resources/assets/rubymod`
